WaveProgressBar · style preview for Tunetastic

Each card is one candidate WaveStyle, drawn with the exact math the real control will use. Progress loops every 24 s. Click a card to pause / resume it — on pause each style collapses into a simple line/bar (dotted for the Equalizer; Comet keeps its look), and expands back into the wave on resume.

Throwaway prototype — only for choosing styles. In the real control this renders through CompositionTarget.Rendering, full scrubbing, and the same NotifyPlaying / NotifyPaused / Seeked API as the current SmoothProgressBar.
