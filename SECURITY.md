# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Tunetastic, please **do not open a public GitHub issue**. Public disclosure before a fix is available could put other users at risk.

Instead, report it privately by emailing:

**amit.ku.p.2806+tunetastic@gmail.com**

Please include:
- A description of the vulnerability
- Steps to reproduce it
- The potential impact, if known
- Your Windows version and where you installed Tunetastic from

I'll acknowledge your report within a few days and keep you updated as the issue is investigated and resolved. Once a fix is released, you'll be credited in the release notes if you'd like.

## Scope

This policy covers the Tunetastic application itself. Third-party libraries used by the project are out of scope — please report those vulnerabilities directly to their respective maintainers.
